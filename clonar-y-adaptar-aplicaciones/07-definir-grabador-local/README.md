# Definir una aplicación a partir de un flujo existente

Estos materiales ayudan a transformar una idea inspirada en aplicaciones existentes en una especificación revisable. El ejemplo utiliza un grabador local de pantalla con cámara opcional e instrucciones para un agente. Es una propuesta de definición: no representa una aplicación terminada ni pruebas ejecutadas.

1. Copia y completa la [plantilla de definición](plantilla-definicion.md) para tu caso.
2. Consulta el [ejemplo del grabador](ejemplo-grabador.md) para ver cómo separar decisiones, preguntas y experimentos.
3. Revisa las [fuentes](fuentes.md) si necesitas profundizar en las referencias.

Vuelve a la definición cuando una observación o un experimento cambie lo que sabes. Registra qué se comprobó y qué sigue pendiente.
