# Ejemplo conceptual: dos equipos y un editor

Dos equipos necesitan abrir, corregir y guardar una copia de documentos. Uno utiliza una plantilla sencilla; el otro necesita un campo de revisión. No se ha construido ni elegido una aplicación real.

Una posibilidad es mantener el guardado como comportamiento común y configurar la presencia del campo. Otra es una extensión con un contrato explícito. También se podría mantener una variante separada si las necesidades o responsabilidades divergen. La decisión depende de quién actualizará cada parte, qué documentos deben conservarse y qué comprobaciones pueden ejecutarse.

Si cambia el guardado, habría que comprobar la copia y sus propiedades para ambas necesidades; si existe intercambio con otra aplicación, se revisaría en cada dirección prometida. No se han ejecutado esas pruebas: el resultado está pendiente.

Antes de elegir el caso práctico, confirma una persona, una tarea completa, una referencia accesible, ejemplos con resultados esperados, recursos y una persona responsable del mantenimiento. Las preguntas abiertas siguen pendientes hasta contar con evidencia.
