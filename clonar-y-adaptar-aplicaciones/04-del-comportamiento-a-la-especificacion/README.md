# Del comportamiento a la especificación

Materiales para convertir una necesidad y su alcance en un encargo que conecte criterios, comprobaciones y evidencia.

## Usar la plantilla

1. Copia la [plantilla del encargo](plantilla.md) a tu editor.
2. Describe el resultado esperado y las condiciones del caso.
3. Relaciona cada criterio con las tareas y comprobaciones que le corresponden.
4. Distingue lo propuesto de lo ejecutado y registra la evidencia obtenida.
5. Si el acuerdo cambia, conserva el motivo y la revisión correspondiente.

Consulta el [ejemplo comentado](ejemplo.md) y las [fuentes](fuentes.md). Si aún no definiste qué conservar, adaptar o excluir, usa primero la [plantilla de alcance](../03-definir-el-alcance/plantilla.md).

La plantilla organiza el trabajo; no ejecuta pruebas ni configura SDD, OpenSpec o KDD por sí sola.
