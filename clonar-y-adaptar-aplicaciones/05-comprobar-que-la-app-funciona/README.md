# Plan de comprobaciones para una aplicación adaptada

Utiliza estos recursos para conectar cada resultado que prometes con casos concretos y evidencia que otra persona pueda revisar.

- [Plantilla para completar](plantilla.md): trabajo, condiciones, documentos, casos y decisión de revisión.
- [Ejemplo conceptual](ejemplo.md): corregir un documento, guardar una copia y recuperar la edición.
- [Fuentes originales](fuentes.md): escenarios, archivos, interfaz, accesibilidad y límites de las pruebas.

## Cómo usar la plantilla

1. Parte del alcance y del encargo que ya acordaste. Identifica qué resultado permitiría terminar la tarea.
2. Prepara documentos con propiedades conocidas y escribe el resultado esperado después de cada edición.
3. Elige casos normales y de fallo según las pérdidas que importan. Si prometes intercambio, incluye cada aplicación, versión y dirección.
4. Ejecuta cada caso y registra resultado, condiciones y evidencia. Mantén como pendientes o bloqueados los casos que no ejecutaste.
5. Revisa los fallos críticos y explica qué aceptas, con qué límites y qué volverás a comprobar después de un cambio.

El ejemplo no contiene resultados de una aplicación construida. La aplicación, su tecnología y el caso práctico siguen por elegir. La plantilla orienta la revisión; no certifica compatibilidad universal ni accesibilidad completa.
