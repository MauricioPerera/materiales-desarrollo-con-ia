# Cómo estudiar una aplicación antes de reconstruirla

¿Qué necesitas observar antes de reconstruir una aplicación con IA? Un botón y una captura no cuentan toda la historia. Aprende a seguir una interacción desde su estado inicial hasta un resultado que puedas comprobar.

Con el ejemplo de guardar una copia de un documento, veremos qué registrar antes y después del clic, qué ocurre al cancelar o fallar y cómo estudiar la recuperación. Al terminar podrás separar hechos, hipótesis y preguntas en un mapa de interacción.
