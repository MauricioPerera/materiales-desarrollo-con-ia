# Mantener acuerdos útiles

Situación: el programa permite quitar una fecha, pero un criterio antiguo todavía dice que no se puede.

Antes de actualizar documentos o código, confirmar el comportamiento deseado. Después revisar la implementación, los criterios y las pruebas que correspondan. Si el documento solo conserva un acuerdo antiguo, identificarlo como historial.

Para evaluar el esfuerzo, observar preparación, revisión, comprobación, correcciones posteriores y mantenimiento. La rapidez de generar texto no mide por sí sola el resultado.

Ejemplo conceptual para estudiar el mecanismo; comprueba los criterios en tu propio contexto.
