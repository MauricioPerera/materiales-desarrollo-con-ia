# El coste real de las especificaciones

Generar una especificación lleva poco tiempo; entenderla, revisarla y mantenerla útil también cuenta. Descubre qué costes reales tiene SDD y qué esfuerzo adicional puede venir de documentos repetidos, contradictorios o desactualizados.

Seguiremos un cambio cuyo código y documentación ya no coinciden. Verás cómo decidir qué acuerdo sigue vigente, por qué más contexto no garantiza más control y qué observar para saber si el esfuerzo de especificar compensa en tu proyecto.
