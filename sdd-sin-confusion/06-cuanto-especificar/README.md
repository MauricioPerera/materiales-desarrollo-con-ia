# ¿Cuánta especificación necesitas?

¿Cuánta especificación necesitas antes de pedir código a una IA? Aprende a ajustar el detalle según tres preguntas: qué falta entender, qué consecuencias tendría un error y qué decisiones necesitará comprender otra persona después.

Compararemos cambiar el texto de un botón, explorar recordatorios y borrar varias tareas. También situaremos la propuesta ODD de Gentle AI para entender cómo puede variar el seguimiento del trabajo. El objetivo es elegir acuerdos y comprobaciones útiles, sin medir la calidad por el número de páginas.
