# Decidir qué referencia se mantiene

Cambio de ejemplo: las tareas pueden tener una fecha límite y ahora también debe poder quitarse.

- Spec-first: preparar el acuerdo del cambio y usarlo para orientar la implementación.
- Spec-anchored: mantener además la especificación como referencia vigente del comportamiento.
- Spec-as-source: identificar la fuente desde la que se deriva el código y llevar a ella una corrección que deba sobrevivir a otra generación.

Estos compromisos pueden combinarse. Conservar un documento como historial es distinto de prometer que describe la aplicación actual. La clasificación orienta la conversación; no es una norma universal.

Ejemplo conceptual para estudiar el mecanismo; comprueba los criterios en tu propio contexto.
