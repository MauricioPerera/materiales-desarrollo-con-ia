# Qué referencia se mantiene

Cambio o comportamiento:

| Pregunta | Acuerdo del equipo |
|---|---|
| ¿Qué documento guía el siguiente cambio? | |
| ¿Es historial o una referencia que debe seguir vigente? | |
| ¿Se mantiene el código directamente o se deriva alguna parte desde otra fuente? | |
| ¿Dónde debe quedar una corrección para sobrevivir a la siguiente generación? | |
| ¿Quién confirma la intención y quién revisa la coherencia? | |
| ¿Qué se actualiza cuando cambia el comportamiento? | |
| ¿Cómo se identifican decisiones sustituidas? | |

No elijas el contrato solo por la etiqueta de una herramienta. Comprueba qué sucede al modificar una función y volver a generar lo que corresponda.
