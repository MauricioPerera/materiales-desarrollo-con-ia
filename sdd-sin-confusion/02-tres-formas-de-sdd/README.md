# Tres formas distintas de trabajar con especificaciones

Spec-first, spec-anchored y spec-as-source: ¿qué cambia entre estas formas de trabajar con especificaciones? La diferencia se vuelve visible cuando modificas una función o corriges un error.

Siguiendo la fecha límite de una tarea, aprenderás qué se conserva, qué debe actualizarse y dónde tiene que quedar una corrección para que sobreviva al siguiente cambio. Usamos la clasificación de Birgitta Böckeler para comparar compromisos, sin asumir que un enfoque sea siempre mejor.
