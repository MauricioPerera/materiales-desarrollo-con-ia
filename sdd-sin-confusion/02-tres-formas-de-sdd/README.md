# Tres formas distintas de trabajar con especificaciones

Materiales para trabajar: decidir qué referencia se mantiene.

## Usar la plantilla

1. Abre la [plantilla](plantilla.md) y copia su contenido a tu editor.
2. Consulta el [ejemplo comentado](ejemplo.md).
3. Completa los campos con las decisiones, condiciones y preguntas de tu caso.
4. Registra la evidencia al comprobar el resultado y revisa lo acordado cuando aprendas algo nuevo.
